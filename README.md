## The common thread

```text
background activity  →  visible state  →  calmer interaction
```

- **Local-first** — useful context stays on the machine whenever possible.
- **Small surfaces** — a floating companion, a sphere, or a pet can be enough.
- **Readable state** — status should be visible without opening another dashboard.
- **Personality matters** — tools can be precise without feeling sterile.
